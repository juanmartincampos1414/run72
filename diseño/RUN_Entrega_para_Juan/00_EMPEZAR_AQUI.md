# RUN · Manual y recursos de marca

La web actual se conserva, incluido su núcleo 3D, materiales, iluminación, movimiento y composición. Sólo se solicita actualizar el logo superior izquierdo y el RUN del fondo con los originales definitivos, manteniendo su ubicación y jerarquía. El resto son recursos de marca disponibles para futuras piezas, no tareas de implementación web.

## Contenido y aplicaciones posibles
- 01_Logotipo: originales SVG y PNG. Usar el vector definitivo para los dos ajustes de logo indicados.
- 02_Simbolo: símbolo para piezas gráficas y futuras aplicaciones de identidad.
- 03_Favicon: recursos disponibles; no se solicita cambiarlo en este alcance.
- 04_3D: renders para presentaciones, propuestas y piezas institucionales; Blender para producir imágenes y GLB como recurso adicional. No sustituir el 3D actual de la web.
- 05_Manual: reglas de marca y ejemplos orientativos; no constituye un plan de rediseño del sitio.
- 06_Plantillas: bases editables para redes y piezas comerciales; adaptar cuando se necesiten.
- 07_Implementacion: alcance de los dos ajustes, comprobaciones y tokens de referencia. No importar los tokens globalmente.

Leer el manual y las guías como documentación de identidad. Implementar sólo los dos ajustes solicitados, mostrarlos en Preview y esperar la revisión antes de publicar.
