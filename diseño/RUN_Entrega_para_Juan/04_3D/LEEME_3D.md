# RUN · Recursos 3D de marca

La web actual se conserva, incluido su núcleo 3D, materiales, iluminación, movimiento y composición. Sólo se solicita actualizar el logo superior izquierdo y el RUN del fondo con los originales definitivos, manteniendo su ubicación y jerarquía. El resto son recursos de marca disponibles para futuras piezas, no tareas de implementación web.

- RUN_Maestro.blend: escena editable para producir imágenes institucionales y comerciales; geometría, materiales, cámara y luces incluidos.
- RUN_Marca_Horizontal.png, RUN_Marca_Cuadrada.png y RUN_Marca_Panoramica.png: composiciones para presentaciones y piezas de marca.
- RUN_Nucleo.png: recurso estático adicional. No reemplazar con él los recursos actuales del sitio.
- RUN_Nucleo_web.glb: modelo adicional disponible para futuros usos evaluados por separado. El nombre del archivo no implica integrarlo en el hero.
- RUN_Parametros_3D.json: registro técnico de esta escena y del export PBR; no parámetros para cambiar la escena web existente.
- crear_escena.py y geometria.json: fuentes reproducibles para Blender.

El GLB aproxima el material de Cycles mediante PBR. No incluye animaciones horneadas. Los materiales y la iluminación descritos corresponden a estos recursos, no a una sustitución de la escena web vigente.
