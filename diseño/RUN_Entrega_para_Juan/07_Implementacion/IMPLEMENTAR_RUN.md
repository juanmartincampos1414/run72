# RUN · Alcance de los ajustes web

La web actual se conserva, incluido su núcleo 3D, materiales, iluminación, movimiento y composición. Sólo se solicita actualizar el logo superior izquierdo y el RUN del fondo con los originales definitivos, manteniendo su ubicación y jerarquía. El resto son recursos de marca disponibles para futuras piezas, no tareas de implementación web.

## Cambios solicitados
1. Logo superior izquierdo: usar 01_Logotipo/RUN-crema.svg sobre oscuro o RUN-oscuro.svg sobre claro. No reconstruirlo con una tipografía ni deformarlo.
2. RUN del fondo detrás del núcleo: usar la geometría del vector definitivo mediante la técnica existente. Mantener la posición, la jerarquía visual y la relación con el núcleo actual.

## Recursos disponibles
Blender y renders: producción institucional y comercial. GLB y parámetros: recursos adicionales para usos futuros que se evalúen por separado. No copiar el GLB al hero ni reemplazar el respaldo actual.
Tokens CSS/JSON y fuentes: referencia para nuevas piezas. No aplicarlos globalmente al sitio existente.
Símbolos y favicons: disponibles para aplicaciones futuras; no implican cambios en Runit, footer u otros componentes.
Plantillas: redes, propuestas y pauta cuando se necesiten. No activan campañas.

## Revisión
Mostrar los dos ajustes en Preview; comprobar desktop y móvil. Conservar el resto del diseño, textos, navegación, CTAs y funciones. No ampliar el trabajo ni publicar a producción sin la revisión acordada.
