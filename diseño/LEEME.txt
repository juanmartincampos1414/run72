¿Cuál uso?
----------------------------------------------------------------
- Web / presentaciones / redes      -> PNG transparente (runit-512/1024)
- Logo o personaje a gran tamaño     -> SVG (no pierde calidad)
- Avatar / foto de perfil / app icon -> runit-icon-* (cuadrado)
- Fondo claro o herramienta sin alpha -> versiones "on-dark"
- Impresión / edición vectorial       -> los .svg

Nota: el personaje funciona mejor sobre fondos oscuros (es su hábitat).
Sobre fondos claros, usá las versiones "icon-dark" o ponelo dentro de
un recuadro oscuro.
